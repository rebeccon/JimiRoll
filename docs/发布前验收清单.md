### ★★ 顺带查出一件重要的事

在干净环境下，**游戏内算出来的地图统计与离线复算完全一致（4/4）**：

| 种子 | 游戏内（只装 JimiRoll） | 离线探针 `QnProbe map` |
|---|---|---|
| `000000N4QW0D` | 12/44 = 27.27% | 12/44 = **27.27%** ✅ |
| `000000N5YC0H` | 13/44 = 29.55% | 13/44 = **29.55%** ✅ |
| `000000N6R9X4` | 20/56 = 35.71% | 20/56 = **35.71%** ✅ |
| `000000N8LYH1` | 14/46 = 30.43% | 14/46 = **30.43%** ✅ |

而在装了 RitsuLib / UnlockTheSpire / Exusiai 的环境里，同一颗种子会出现偏差
（例：`000000N6R9X4` 进程内曾算出 16/54，而干净环境与离线探针都是 20/56）。

**⇒ 结论：地图生成的结果会受"当前装了什么模组"影响**（RitsuLib 的
`Dynamic act content patching` 等会在运行期改动 act 内容）。
这既是"离线探针不能当验收标准"的原因，也是**交付前必须在主线程复核**的原因 ——
玩家这一局的图是在主线程、在同一个模组环境下生成的，所以只有主线程那一次的值作数。

## E. 真实存档交叉验证（最有说服力的一项）

**复现**：用它给的种子在游戏里开一局，打完/退出后读

**结果**：作者实测的那一局

```

act1 节点: 17（走完了整章）

           → unknown → rest_site → boss
```

| 口径 | 怪物占比 |
|---|---|
| 本模组**交付时**写的值 | 12/47 = **25.53%** |
| 离线探针独立复算 | 12/47 = **25.53%** ✅ |

## 结论

- **可以发布。** A~F 全部通过。
- 发布物：`dist/JimiRoll-2.2.0.zip`（解压后整个 `JimiRoll` 文件夹丢进游戏 `mods\` 即可）。
- 已知限制（写进了 README）：
  1. **游戏的地图生成会被"当前装了什么模组"影响**，同一颗种子在不同模组环境下算出来的
     怪物占比可能不同 ⇒ 本模组用「交付前主线程复核」保证你拿到手的那一局是达标的。
  2. **不要开多线程**（`WorkerCount` 保持 1）：实测 8 线程会让游戏无征兆退出。
  3. 离线探针只是开发工具，**不能**当验收标准；验收标准是游戏主线程上的值。
